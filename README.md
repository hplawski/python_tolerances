# python_tolerances

# Python practice for quality inspection

Small Python scripts I'm writing as a beginner in Python with Harvard's
CS50P course. Each one automates a simple quality assurance task.

## Scripts

- **tolerance.py**: asks for a measured value and checks it against a
  nominal value and tolerance. Prints PASS, or FAIL with a reminder to
  raise a non-conformance.

## How to run

    python tolerance.py
